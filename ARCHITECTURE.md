# README Tools - System Architecture

## Overview
README Tools is a suite of intelligent tools for managing, organizing, and discovering content within large README.md files, optimized for AI agent integration.

## System Architecture

### Core Components

#### 1. README Organizer Tool (`readme_organizer/`)
Main tool for breaking down large README files into categorized, searchable parts.

**Components:**
- **Parser Module** (`parser.py`)
  - Markdown parsing and structure extraction
  - Heading hierarchy analysis
  - Content block identification

- **AI Categorizer** (`categorizer.py`)
  - Multi-provider AI integration (OpenAI, Anthropic, OpenRouter, Ollama)
  - Intelligent category detection
  - Keyword and tag generation
  - Section summarization

- **Storage Layer** (`storage.py`)
  - SQLite database with FTS5 full-text search
  - Schema: readme_parts, categories, keywords, tags, search_index
  - Atomic transactions for consistency

- **Indexing Engine** (`indexer.py`)
  - Full-text indexing with SQLite FTS5
  - Keyword extraction and weighting
  - Tag management and categorization
  - Vector embeddings (optional, for semantic search)

- **Search Engine** (`search.py`)
  - Full-text search with ranking
  - Keyword-based filtering
  - Tag-based discovery
  - Section extraction
  - Relevance scoring

- **Context Provider** (`context_provider.py`)
  - Smart section delivery for AI agents
  - Context window management
  - Relevance-based content selection
  - Progressive context loading

#### 2. API Layer (`api/`)
FastAPI-based REST API for all tools.

**Endpoints:**
- `POST /api/v1/readme/parse` - Parse and organize README
- `GET /api/v1/readme/parts` - List all parts
- `GET /api/v1/readme/parts/{id}` - Get specific part
- `GET /api/v1/search` - Full-text search
- `GET /api/v1/search/keywords` - Keyword search
- `GET /api/v1/search/tags` - Tag-based discovery
- `POST /api/v1/context/request` - AI agent context request
- `GET /api/v1/categories` - List categories
- `GET /api/v1/keywords` - List keywords
- `GET /api/v1/tags` - List tags

#### 3. AI Provider Adapters (`ai_providers/`)
Abstraction layer for multiple AI providers.

**Providers:**
- `openai_adapter.py` - OpenAI GPT-4/GPT-4-turbo
- `anthropic_adapter.py` - Anthropic Claude
- `openrouter_adapter.py` - OpenRouter (unified access to 100+ models)
- `ollama_adapter.py` - Local Ollama models
- `base_adapter.py` - Common interface

#### 4. Configuration (`config/`)
- `settings.py` - Application settings
- `ai_config.yaml` - AI provider configurations
- `categories.yaml` - Category definitions

## Data Flow

### README Processing Flow
```
README.md
    ↓
Parser (extract structure)
    ↓
AI Categorizer (analyze & categorize)
    ↓
Indexer (create indices)
    ↓
Storage (SQLite + FTS5)
```

### Search & Discovery Flow
```
Search Query
    ↓
Search Engine (FTS5 + filters)
    ↓
Ranking & Scoring
    ↓
Results + Excerpts
```

### AI Agent Context Flow
```
Agent Request (topic/keywords)
    ↓
Context Provider (analyze relevance)
    ↓
Select Relevant Sections
    ↓
Format & Deliver (within context window)
```

## Database Schema

### readme_parts
```sql
CREATE TABLE readme_parts (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    category TEXT NOT NULL,
    parent_id TEXT,
    order_index INTEGER NOT NULL,
    metadata JSON,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### keywords
```sql
CREATE TABLE keywords (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    part_id TEXT NOT NULL,
    keyword TEXT NOT NULL,
    weight REAL DEFAULT 1.0,
    FOREIGN KEY (part_id) REFERENCES readme_parts(id)
);
CREATE INDEX idx_keywords_keyword ON keywords(keyword);
```

### tags
```sql
CREATE TABLE tags (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    part_id TEXT NOT NULL,
    tag TEXT NOT NULL,
    FOREIGN KEY (part_id) REFERENCES readme_parts(id)
);
CREATE INDEX idx_tags_tag ON tags(tag);
```

### categories
```sql
CREATE TABLE categories (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL UNIQUE,
    description TEXT,
    parent_category TEXT,
    FOREIGN KEY (parent_category) REFERENCES categories(id)
);
```

### search_index (FTS5 Virtual Table)
```sql
CREATE VIRTUAL TABLE search_index USING fts5(
    part_id UNINDEXED,
    title,
    content,
    keywords,
    tags,
    category
);
```

## Technology Stack

- **Language**: Python 3.11+
- **Web Framework**: FastAPI
- **Database**: SQLite with FTS5
- **AI Providers**: OpenAI, Anthropic, Ollama
- **Markdown Processing**: python-markdown, markdown-it-py
- **Testing**: pytest, pytest-asyncio
- **Documentation**: OpenAPI (auto-generated by FastAPI)

## Deployment

### Development
```bash
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
uvicorn api.main:app --reload
```

### Production
```bash
uvicorn api.main:app --host 0.0.0.0 --port 8000 --workers 4
```

### Docker
```bash
docker build -t readme-tools .
docker run -p 8000:8000 readme-tools
```
